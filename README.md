# Digiman - Music Player
### Author: Evan Gilbert
### Github: e-tachyon

## Description
The Digiman is a digital music player. It is intended to function like an ipod, allowing you to add songs and create playlists. It uses sqlite3 to hold the song informantion. For audio it uses miniaudio's low level interface to implement the audio. The project is cuttently still under development and the current state is a proof of concept. 

## Current Features
- Play/Pause
- Volume Control
- Add Song (terminal) (current version only adds to first position in table)

## Planned Features
- Create and Delete Playlists
- Queue Songs
- Shuffle Play
- GUI (Qt framework)
- Add songs through Dolphin GUI
- Playback Speed
